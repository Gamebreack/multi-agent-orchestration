# Onboarding — answer all at once, one pass

Copy your answers into CONTEXT.md. Configure the factory, not the product:
system-level choices only, nothing about a single run.

1. What is this workspace for? (one sentence; becomes CONTEXT.md's opening)
2. What already exists that work here touches? (paths; they become the
   routing table)
3. What is out of scope? (the "not touching" list every work item inherits)
4. Which conventions file loads for agents here? (AGENTS.md / CLAUDE.md /
   none)
5. Where does the work index live, and where do item files live? (defaults:
   backlog.md at the root, items/ beside it)
6. Is there a glossary (naming authority)? (optional — skip to use none)
7. Who signs off at checkpoints, and where is finished work recorded?
   (default: the operator; a done ledger)
8. What must never enter this workspace? (secrets policy, portability
   boundary)
