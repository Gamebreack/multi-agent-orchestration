## Outcome

MAO ships tool-neutral global instructions, role skills and an agent-run setup procedure
instead of per-harness files and installers, with no personal data or model IDs, so the repo
can be made public. Known when: `core/` exists, the removed paths are gone, and the
personal-data and model-ID greps come back clean.

## Cut

Per-harness enforcement (the read-only primary-agent hook, permission arrays) and the benchmark
harness are gone: a harness now gets only the native limits `mao-setup` can map from each
role's access level, and some harnesses (no tool limits) get prompt-only enforcement.
Installer scripts are replaced by a procedure an agent runs, which is less deterministic.
