# b03: Separate shared policies from harness adapters and optional presets

## Outcome

A replicator can tell, for every toolkit file, whether it is shared policy, a harness adapter, or an
optional preset — and models/providers are parameterized so the toolkit installs on machines without
the author's provider auth. Operator confirms by walking the separation.
